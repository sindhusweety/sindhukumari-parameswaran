Open Source · In Progress

Live Chat Translator

An on-device overlay that translates chats in WhatsApp, Snapchat, and Messenger without sending a word to a server. The core runs on Python and Argos Translate, wrapped in platform-specific shells — Kotlin and Chaquopy for Android, keyboard and share extensions for iOS, PyQt6 with OCR for desktop, and a Chrome extension for the web. The monorepo, translation core, CI, and Android scaffold are done; right now I'm testing a two-stage pipeline that runs romanized Hindi through IndicXlit before handing it off to Argos Translate for Hinglish support.

Conference Talk · NVIDIA GTC, March 2019
